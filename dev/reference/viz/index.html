radrs.viz¶

Visualization helpers for interactive raystack visualization.

This module provides:

  • sweep and moment selectors over raystack DataTree nodes
  • a vectorized adapter from sweep data to polar point buffers
  • an optional anywidget polar renderer for marimo notebooks

FoldedWaterfallPayload dataclass ¶

Row-per-return view of the folded returns matrix.

Unlike :class:WaterfallPayload, rows are not strided: a window of consecutive returns is shown verbatim so every fold is visible. Returns chunked from one radial share a return_time, and group_starts marks where each such set of folds begins.

n_groups property ¶

Number of fold sets in the window.

prepare_folded_waterfall_payload(returns, moment, *, row_offset=0, row_count=512, max_range=None) ¶

Create a row-per-return payload over a window of the returns matrix.

Rows are taken verbatim (no striding), so every fold in the window is drawn. Folds chunked from one radial share a return_time; the boundaries between those sets are returned in group_starts for the renderer to divide on.

Parameters:

Name Type Description Default
row_offset int

Window into the return_time dimension, clamped to the dataset.

 0
row_count int

Window into the return_time dimension, clamped to the dataset.

 0
max_range int | None

Cap on drawn range columns; None (default) keeps every gate. Folds are usually narrow enough to draw whole.

 None
